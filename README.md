# Estancias formativas y de investigación · IAPH (maqueta)

Tercera propuesta de mejora visual del área **Formar y difundir** del IAPH, pensada para **GitHub Pages**. No es una página oficial ni un sistema real de solicitud.

## Publicar
1. Crea un repositorio de GitHub, por ejemplo `IAPH-Estancias-Demo`.
2. Sube el contenido de esta carpeta, de forma que `index.html` quede en la raíz del repositorio.
3. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Abre `https://USUARIO.github.io/IAPH-Estancias-Demo/`.

## Funcionamiento
- Navegación superior y versión móvil.
- Banner panorámico alojado **dentro** del repositorio, sin depender de enlaces externos.
- Tres modalidades seleccionables (grado y posgrado; profesionales; investigación) y panel que muestra destinatarios, quién presenta la solicitud, requisitos y el PDF correcto.
- Secuencia orientativa de tramitación, preguntas frecuentes y contacto.
- Los PDF remiten a las fuentes oficiales de la Junta de Andalucía. La demo no recoge datos, envía solicitudes ni asigna plazas.

## Adaptación a Drupal
La cabecera/pie se conservarán **desde el tema corporativo**. Imagen panorámica, columnas y enlaces son patrones existentes en el portal, pero sus componentes concretos han de validarse con la unidad técnica. El panel de modalidades puede adaptarse como 3 bloques o páginas interiores, **sin JavaScript personalizado**, si el editor no admite scripts. Véase `docs/Informe_Justificativo_Estancias_IAPH_2026.pdf`.

## Imágenes, marca y derechos
El logotipo de cabecera es una muestra recortada de una captura facilitada para la maqueta. Las fotografías panorámicas son imágenes **conceptuales generadas con IA** para esta demostración, no fotografías del IAPH ni de estancias reales. Para la web oficial deben sustituirse por imágenes institucionales autorizadas y gestionadas en su mediateca. No se atribuyen al IAPH actividades o personas representadas en las imágenes.
